Build gym routines and look up exercises.

myGainz lets you look up exercises with demo animations and save routines to your own account, starting from a preset or building your own.

Open the app View source

Features

Exercise lookup

Browse and filter the ExerciseDB catalog by name, muscle group, or equipment. Each exercise has a demo animation.

Programs

Start from the starter routines or build your own from existing and custom exercises.

Saved per user

Sign in with Google and your routines are stored in your own Firestore document.

Daily motivation

The home page pulls a quote from the Type Fit quotes API.

Screenshot

Built with

React 18, React Router 6, Tailwind CSS, Firebase Auth and Firestore, ExerciseDB, and Type Fit.

To run it locally: clone the repo, then in mygainz/ run npm ci and npm start.
